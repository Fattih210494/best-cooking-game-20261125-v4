# Lentera Rasa — Pasar Malam 3D

Game masak 3D (Three.js) di stan pasar malam Indonesia: awning merah-putih, lampion menyala, wajan berapi, grill arang, dan koki kecil yang berlari antar stasiun. Ambil 3 bahan (tombol 1-8), masak di stasiun dengan timing — pull tepat di zona emas untuk PERFECT SEAR — plating, lalu bunyikan bel untuk menyajikan sebelum pelanggan kehabisan sabar. Target shift: 1.500 poin atau 10 piring dalam 2:30. Buku Menu (M) berisi 8 resep Indonesia: Nasi Goreng, Satay Platter, Volcano Mee, Lime Broth, Chili Greens, Soy Noodles, Ember Laksa, Sultan Feast.

## Run it

```sh
node serve.ts
# buka http://localhost:8080
```
